# Quanta Solar — landing page

Página estática lista para GitHub Pages (sin dependencias ni compilación).

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub y sube todo el contenido de esta carpeta (`index.html` debe quedar en la raíz).
2. En el repositorio entra a Settings > Pages.
3. En "Build and deployment" elige "Deploy from a branch", rama `main` y carpeta `/ (root)`. Guarda.
4. En uno o dos minutos tu página estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Antes de publicar
- En `index.html` busca `#cotizador` y cambia el `href` de los botones "Abrir cotizador" por el enlace real de tu cotizador.

## Archivos
- `index.html`: página completa (HTML + CSS).
- `assets/`: favicon, símbolo del logo e ilustración con su leyenda.
